# Predicting_Heart_Disease_Risk

## Overview
This project builds predictive models to identify the presence of heart disease using clinical patient data. The goal is to demonstrate end-to-end data analysis and machine learning skills relevant to clinical data science and healthcare analytics.

Two modeling approaches were implemented:
- Logistic Regression (statistical modeling)
- Random Forest (machine learning)

The project emphasizes data cleaning, reproducibility, model evaluation, and clinical interpretation.

## Dataset
This project uses the UCI Heart Disease dataset, which contains clinical variables such as:
Age
Sex
Chest pain type
Blood pressure
Cholesterol
Maximum heart rate
ECG results

## Outcome Variables
0 = no heart disease
1 = heart disease

Key Analysis include:
- Age distribution of patients
- Heart disease prevalence by sex
- Distribution of clinical variables

## Research Question
Predict whether a patient has heart disease based on clinical features. 
Which clinical factors are most predictive of heart disease, and how accurately can statistical and machine learning models identify at-risk patients?

## Methods
The analysis includes:

1) Clinical data analysis
2) Data cleaning and preprocessing
3) Statistical modeling (logistic regression)
4) Machine learning (Random Forest)
5) Model evaluation (ROC, confusion matrix)
6) Data visualization in RStudio
7) Reproducible research workflows
